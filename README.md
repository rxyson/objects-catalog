# Лабораторная работа 3. Каталог объектов

## Возможности

**Книга (`Book`)**
- создание книги с проверкой всех полей при создании;
- недопустимая книга (пустое название, автор, категория или ID, год вне диапазона, число страниц <= 0) не создаётся — выбрасывается `IncorrectEntityError`.

**Каталог (`Catalog`)**
- добавление книги — `add(book)`; повторный ID запрещён;
- получение книги по ID — `get(item_id)`; отсутствующий ID вызывает ошибку;
- удаление книги — `remove(item_id)`; отсутствующий ID вызывает ошибку;
- поиск по категории — `find_by_category(category)`;
- поиск по части названия без учёта регистра — `find_by_name(query)`;
- очистка каталога — `clear()`;
- количество книг — `len(catalog)`;
- проверка наличия — `"b1" in catalog`;
- перебор книг в порядке добавления — `for book in catalog`;
- методы поиска возвращают новый список, изменение результата не затрагивает каталог.

**Хранение (`storage`)**
- сохранение каталога в JSON;
- загрузка каталога из JSON;
- в корне файла хранится `format_version` (поддерживается версия 1);
- повреждённый файл вызывает ошибку, при этом существующий каталог не изменяется.

## Описание

Пакет `library_catalog` с предметной моделью книги и каталогом книг.

- `models.py` — сущность `Book` (dataclass). Поля: `item_id`, `title`, `category`, `year`, `author`, `pages`. Инварианты проверяются при создании, неверная книга вызывает `IncorrectEntityError`.
- `catalog.py` — класс `Catalog`. Хранит книги в словаре по ID. Методы: `add`, `get`, `remove`, `find_by_category`, `find_by_name` (без учёта регистра), `clear`, а также `len()`, `in` и перебор `for`.
- `storage.py` — сохранение и загрузка каталога в JSON (`format_version: 1`). Повреждённый файл не меняет существующий каталог.
- `exceptions.py` — базовая `CatalogError` и её наследники.

**Порядок итерации:** книги перебираются в порядке добавления в каталог.
